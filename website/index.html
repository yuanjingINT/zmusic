网易云音乐

01 — 功能

为音乐而生的终端工具。

01

搜索与发现

关键词搜索歌曲、歌单、专辑与艺人。推荐歌曲、新专、个性化歌单，全部来自网易云。

02

播放与歌词

底层由 mpv 驱动，支持进度、暂停、切歌、音量。实时同步滚动歌词，含翻译。

03

下载与收藏

批量下载选中歌曲到本地目录。收藏歌曲与歌单，随时回听。

04

超级下载

插入 U 盘，一键格式化并填充热榜歌曲，离线音乐库自动就绪。

05

USB 设备

自动检测 U 盘，挂载、测空余空间、下载位置可切换本地或 U 盘。

06

自动 API

每次启动自动更新 NeteaseCloudMusicApiEnhanced 服务并重启，解灰逻辑已修补。

02 — 安装

三步即可运行。

需要 Rust 工具链、Node.js 22+ 与 mpv。支持 Arch / Fedora 等 Linux 发行版。

01

克隆仓库

git clone https://github.com/yourname/zmusic.git
cd zmusic
02

编译并安装

./install.sh

编译 release 版本，安装 zmusic 命令与桌面启动器。

03

启动

zmusic

首次启动自动安装并启动 API 服务。

04 — 技术

小而锋利。

  • Rust 2021编译型，内存安全，启动毫秒级
  • ratatui 0.29终端 UI 框架
  • crossterm 0.28跨平台终端事件
  • reqwest (rustls)HTTP 客户端，纯 Rust TLS
  • serde / serde_json序列化与配置
  • mpv (IPC)音频播放与进度同步
  • NeteaseCloudMusicApiEnhanced网易云 API 服务
  • systemd --userAPI 服务守护与自动更新
